# Optional local wallpapers and presets

All 50 approved presets use independent color palettes and individual vector motifs, without downloading or bundling default wallpaper photographs. Original gold remains preset 00. GTA VI (01), Greek God of War (12) and Metallica Snakebyte (42) use the user-approved miniature header art. The original LiveArea icon is unchanged.

Settings > Appearance > Theme presets. Primary and secondary colors remain editable independently, even after selecting a preset. Wallpaper files displays the active preset's filename pattern. Copy an optional JPEG or PNG through VitaShell to ux0:data/VitaPlus/Wallpapers/NN-1.jpg (or .png), NN-2 and NN-3, where NN is the active preset's two-digit ID. Recommended 960x544, max 1024 per side and 2 MiB. Reload local images after replacing files; deleting originals removes them on the next reload. Only validated local files are decoded. No remote image URLs.

The optional three wallpapers rotate every 60 seconds while in the menus, with a switch to disable. Missing or invalid files fall back to the procedural theme. A single local worker handles bounded decoding and cache I/O when account/play workers are idle. The originals are NEVER removed. Only generated .pvw cache files in ux0:data/VitaPlus/Cache/Themes/ are eligible for automatic deletion, after ten days since the last use; the current theme is exempt, and invalid/backward clocks do not trigger deletion. Cache storage is bounded by 51 presets x 3 slots x ~510 KiB. Each cached image has metadata and a checksum. The cache uses 480x272 pixels scaled to the display to reduce RAM and storage. No new download work or wallpaper rotation while streaming. New wallpaper menu help is translated in English and Portuguese, with fallback elsewhere.

This is a test build on update/vitaplus-themes-latency. Hardware visual and performance validation is pending.

## Storage migration

Native adaptive builds migrate only ux0:data before starting workers. Account, Settings, Imports, Cache/Covers, Cache/Themes, Cache/PS5-Catalog, Wallpapers, Logs/Archive and Captures are under VitaPlus. Existing directories are renamed on the same volume, or merged without replacing different files; duplicate files are deleted only after byte comparison. A conflict pauses startup. Unrelated files are untouched. Automatic vault keys remain at the original ur0:data/plus-vita/account.key, separate from the encrypted account in ux0:data/VitaPlus/Account/account.json. The migration never accesses ur0; only normal vault operations access its dedicated key file and temporary key file. No system or jailbreak files are modified. Existing keys remain in place. Password vaults remain available. Back up private data before testing; older versions expect old paths. Updates downloader and self-installation are not implemented by this change.
