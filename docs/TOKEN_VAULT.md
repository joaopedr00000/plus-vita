# Local token protection (experimental)

Remembered account data is always encrypted with AES-256-GCM, fresh system-generated nonce and authenticated header. The existing account.json filename is retained for atomic migration; contents are binary.

- Default automatic unlock (PVV2): a random 256-bit key stored separately at ur0:data/plus-vita/account.key, not inside the encrypted account file or executable. No password prompt. This protects against copying the account file alone, not against full filesystem access or a compromised device. ur0 is not a hardware-backed keystore. If the internal partition is inaccessible, saving fails rather than falling back to plaintext. Loss of the key requires fresh sign-in.
- Optional startup password (PVV1): PBKDF2-HMAC-SHA256, 200,000 iterations and random salt. A strong local 12–64 character password is required to unlock. Never reuse a Sony password. Enable or disable via Settings > Security and privacy > Startup password. Existing password vaults retain their protection until the user unlocks and explicitly switches off prompting. The old password must be provided to switch off. Switching on removes the automatic key after successful replacement. Forgotten password: forget and sign in again.

The staged encrypted file is authenticated before replacing an existing account. All existing login methods remain available. Local HTTP and imported JSON remain plaintext. On v0.0.3, successful encrypted saves automatically remove the known imported JSON only if its token matches the saved account, after the installed vault is reopened and authenticated. If verification, cleanup or token matching fails, retain the source; a cleanup warning does not disable Remember. The encrypted account.json remains necessary for restoration. Copies on other devices, old backups and flash remnants may still exist. No protection against runtime memory access. Never share the key file. Downgrading requires fresh sign-in. Native filesystem behavior and performance need testing on physical Vita hardware.
