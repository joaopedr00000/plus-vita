# Installer handoff — internal test only

User observed 0x80101114 at stage 8 from B1 to B2: downloaded and verified, promotion rejects the running title. Cross-reference VitaSend changelog and src/plat_vita.c, VitaShell native promoter. Independent implementation using separate PLVTU0001 helper: same current executable, separately staged SFO and header, fixed handoff metadata, SHA-256 recheck, no direct replacement of running main. The helper runs before networking/account startup, closes the other foreground app using the native AppMgr API, promotes only verified PLVTB0001, checks APP_VER, writes result, relaunches main once. Main consumes receipt and only removes helper after matching its exact executable hash/title. Interrupted or failed install preserves VPK in ux0:Downloads/VitaPlus-update.vpk; unknown reserved ID is not overwritten. Helper may leave a bubble if cleanup fails. The explicit install action can close another suspended app. Never deletes main, account, settings or save data. Hardware testing is mandatory: manual installation of this build is needed first; then a distinct newer test build must be offered to validate the full path. This branch does not publish releases and retains the B2 identity only for CI smoke testing.
