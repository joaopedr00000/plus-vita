# Installer handoff — public B3 beta

User observed 0x80101114 at stage 8 from B1 to B2: downloaded and verified, promotion rejects the running title. Cross-reference VitaSend changelog and src/plat_vita.c, VitaShell native promoter. Independent implementation using separate PLVTU0001 helper: same current executable, separately staged SFO and header, fixed handoff metadata, SHA-256 recheck, no direct replacement of running main. The helper runs before networking/account startup, closes the other foreground app using the native AppMgr API, promotes only verified PLVTB0001, checks APP_VER, writes result, relaunches main once. Main consumes receipt and only removes helper after matching its exact executable hash/title. Interrupted or failed install preserves VPK in ux0:Downloads/VitaPlus-update.vpk; unknown reserved ID is not overwritten. Helper may leave a bubble if cleanup fails. The explicit install action can close another suspended app. Never deletes main, account, settings or save data. Hardware testing is mandatory: manual installation of this build is needed first; then a distinct newer test build must be offered to validate the full path. Public B3 uses version v0.0.6-b3, APP_VER 00.30 and the existing main title ID PLVTB0001. Publish only after both build and application test jobs pass. The stable release and PS5 hardware release gate remain unchanged.
