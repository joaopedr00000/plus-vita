# Stable direct updater
The B5 to B6 procedure was confirmed on physical hardware by the maintainer. 0.0.7 uses the native direct update by default for newer eligible GitHub release packages with unchanged ancillary resources, retaining the helper for incompatible packages. The B6 updater itself cannot use direct installation for 0.0.7, due to its hard-coded test pair.
The existing VPK extraction, title and SFO ordering checks and SHA256 verification remain. A transaction records original and incoming file hashes; only known mixed files are restored automatically. Unknown content is not overwritten. After successful display initialization the transaction's own backup files are retired; an intact rolled-back app can retry. Confirmed legacy B6 backups can be retired after a newer normal promotion if the original hashes and version are verified. No arbitrary local candidate is accepted. The VPK remains available for manual recovery after direct installation. A power interruption may still require reinstall via VitaShell, especially if eboot.bin is missing. Hardware testing of generalized repeated updates remains pending.
