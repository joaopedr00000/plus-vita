## English
- **New default internal updater:** direct installation and automatic restart, inspired by VitaDB Downloader and successfully tested on a physical PS Vita during B5 → B6.
- Removes the experimental label and version-pair restriction. Verified VPK, SHA-256, backup and rollback remain; completed transactions are retired so future updates can run.
- The helper remains a fallback for packages with changed resources or when direct preparation is unavailable.
- Updating from older versions to 0.0.7 still uses the updater already installed; the new default applies to subsequent updates from 0.0.7. The generalized implementation has not yet been hardware-tested across multiple consecutive updates.

## Português (Brasil)
- **Novo atualizador interno padrão:** instalação direta e reinicialização automática, inspirado no VitaDB Downloader e testado com sucesso em um PS Vita real na transição B5 → B6.
- Removida a identificação experimental e a limitação de versões. Verificação do VPK, SHA-256, backup e rollback mantidos; transações concluídas são encerradas para permitir futuras atualizações.
- O auxiliar permanece como alternativa para pacotes com recursos diferentes ou quando a preparação direta não é possível.
- A migração de versões anteriores para a 0.0.7 ainda usa o atualizador instalado anteriormente; o novo padrão vale para as próximas atualizações a partir da 0.0.7. A implementação generalizada ainda não foi testada em várias atualizações consecutivas no console.

## Español
- **Nuevo actualizador interno predeterminado:** instalación directa y reinicio automático, inspirado en VitaDB Downloader y probado con éxito en una PS Vita física durante B5 → B6.
- Se elimina la etiqueta experimental y la restricción entre versiones. Se mantienen la verificación del VPK, SHA-256, copia de seguridad y reversión; las transacciones completadas se cierran para permitir futuras actualizaciones.
- El asistente sigue disponible cuando cambian otros recursos o no es posible preparar la instalación directa.
- La transición desde versiones anteriores a 0.0.7 utiliza el actualizador ya instalado; el nuevo método predeterminado se aplica a futuras actualizaciones desde 0.0.7. La implementación generalizada aún no se ha probado en varias actualizaciones consecutivas en la consola.
