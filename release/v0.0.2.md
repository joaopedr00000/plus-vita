# VitaPlus v0.0.2 — Visual Update

This release focuses on refreshing the visual identity of VitaPlus.

### Visual changes

- Rebranded the application as VitaPlus.
- New PlayStation Plus Cloud Streaming bubble icon.
- Redesigned LiveArea featuring a PS Vita with the cloud streaming artwork fitted inside its screen.
- New black, graphite, gold and white interface theme.
- Matching colors across menus, settings and the game catalogue.

No new streaming features are introduced in this release.
