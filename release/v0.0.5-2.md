# VitaPlus v0.0.5-2 — Refined Library (Final)

A visual refinement of the published v0.0.5, based on the approved black-and-gold design reference. PS5 cloud streaming remains experimental and unavailable for supported gameplay; support is in development.

- The exact README logo is embedded in the app header, with its surrounding background cropped for the header. The LiveArea icon, bubble and splash are unchanged.
- Native 960×544 layout, gold ribbon background, compact seven-row library, rounded cover thumbnails, platform badges, pill filters, search with magnifier, large selected cover, gold Play button and PlayStation-style footer symbols.
- Console clock, battery percentage and network connection status are read from native system APIs (hidden if unavailable). Footer retains the real catalogue count. Square searches, Triangle cycles filters, Cross launches, Circle goes back; touch tabs and buttons retain their real hit targets.
- Accurate catalogue title, platform and identifier; eligibility is checked during launch. No invented descriptions, install sizes, region values, playtime, trophy counts or playback availability. Artwork uses the available Sony images, preserving aspect ratio for the main preview.
- All v0.0.5 streaming, account, cache, privacy and localization functionality retained.
- Public version v0.0.5-2; APP_VER 00.22; title ID PLVTB0001. VPK and SHA-256 checksum are published only after automated tests and package verification. Physical Vita visual validation remains pending.
