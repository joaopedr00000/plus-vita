# VitaPlus v0.0.4 — Search and latency

**Experimental pre-release.** Native hardware verification and measured end-to-end input latency remain pending.

- Game title search using the Vita keyboard, Square shortcut and touch; platform filtering remains independent. Clear search preserves platform selection.
- **PS5 cloud streaming is currently unavailable.** Support is planned and under development; no release date is confirmed. PS5 entries retain an explicitly labelled experimental test path.
- Video presentation catches up when decoded output is stale, while preserving compressed H.264 reference order. First and recovery pictures are always presented; catch-up presentation interval is bounded.
- Adaptive reorder grace increases on recovered late frames rather than on loss alone; audio queue capacity follows the prebuffer target (9–15 ten-millisecond units), with fade-in after local eviction.
- Neutral controller state after 100 ms without a successful sample (not a network round-trip measurement). Retains independent 4 ms polling and control mapping; avoid building a redundant default mapping each poll.
- HUD reports local compressed queue depth/age and skipped presentations alongside FPS, receive bitrate, RTT estimate and decode time. None is physical input-to-display latency.
- Public version 0.0.4, internal APP_VER 00.20; title ID PLVTB0001 unchanged. Prior v0.0.3 remains available. Back up saved account/key privately before upgrading.

## Inspiration and compatibility

Independent adaptations of short queues, late-frame presentation and controller recovery concepts documented by [Chiaki-ng](https://chiaki-ng.github.io/chiaki-ng/updates/releases/) and [Vita Moonlight](https://github.com/xyzz/vita-moonlight/releases). No external client code copied; no change to Sony authentication or entitlement checks, stream codec, reference guards, or original branding.
