# VitaPlus 0.0.6 B2 — Audio Recovery and Diagnostics

## English
- Recover missing packed PS3/PS4 audio units using redundant data already supplied by the server, before Opus loss concealment.
- Ignore duplicate audio units; handle 16-bit sequence wraparound.
- With adaptive audio enabled, allow a brief wait of up to 12 ms before a full buffer refill. Smooth recovery after longer sequence gaps.
- Extended private local diagnostics: queue age, drops, concealment, refill duration, output stalls, PCM trim and discarded samples, redundancy recovery.
- Retains B1's My Games filter, experimental PS5 session authorization, updater improvements and streaming options.
- Thanks to the user who reported audio crackling and delay in The Last of Us Remastered and God of War (upstream issue #55). Two complete sessions were analyzed. The old log lacks audio output counters, so the exact root cause and the improvement on hardware are not confirmed.
- I cannot test this build on my PS Vita right now. Please send feedback and the new local diagnostic log, especially after 10–15 minutes of PS4 streaming, noting bitrate, settings and whether WifiTurbo is enabled. Do not include credentials. PS5 remains experimental. The private Ponte Live upload service is not integrated yet.
- Public beta; select the Beta update channel or install manually using VitaShell if the internal installer fails. The stable release remains 0.0.6.
