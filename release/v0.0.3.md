# VitaPlus v0.0.3 — Privacy and regional policy

Development candidate; not a verified public VPK release.

- Reopen and authenticate the installed encrypted vault before automatically removing a matching plaintext import at `ux0:data/plus-vita-auth.json`. Failed saves or verification preserve the source; different tokens and failed cleanup retain the import. Cleanup warnings do not turn Remember off. The encrypted account file and separate key (or local password) remain necessary for restoration.
- Regional discovery uses authenticated account country and language, not foreign locale overrides. Legacy US/CA/PT choices migrate to a single opt-in same-account discovery setting. Fallback requires successful authentication/session/transport and HTTP 404 from the legacy store; 401/403/429 and other failures do not trigger it. Catalogue discovery is not streaming authorization.
- Manual server selection remains in every country; future automatic failover is restricted to verified eligible users in supported countries (see ROADMAP).
- Public version v0.0.3; internal APP_VER 00.19; title ID PLVTB0001 unchanged.
- PS5 and GTA VI remain experimental/unverified. No guarantee against Sony restrictions.
- CI and physical-device Remember/restart, cleanup, region and PS3/PS4 playback checks remain release gates.
