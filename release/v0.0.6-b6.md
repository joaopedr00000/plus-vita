# VitaPlus 0.0.6 B6 — Direct Update Target

## English
- Test target for B5 → B6 after confirmation that B5 installed on a physical Vita.
- Select Beta, download the update, then choose Install and restart (experimental). The direct path verifies the VPK, backs up the executable and metadata, and requests a native restart. Incompatible resources use the existing helper.
- If the screen stays black, wait for installation to finish and reopen manually. Report the displayed version and whether it restarted by itself. Recovery and restart are still experimental; retain the B5 VPK for repair if necessary.
- Stable channel unchanged.
