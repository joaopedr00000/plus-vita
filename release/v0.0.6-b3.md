# VitaPlus 0.0.6 B3 — Internal Updater Fix

## English
- New experimental self-update flow using a separate temporary installer title (PLVTU0001), addressing the reported stage 8 error 0x80101114 when the system refuses to replace the running app.
- The helper rechecks the verified VPK, closes the previous foreground app, installs VitaPlus, checks the installed APP_VER and requests a single relaunch. The main app attempts ownership-checked helper cleanup at the next start.
- Existing accounts, settings and the main title ID are preserved by design. Failed installations retain the verified package in ux0:Downloads/VitaPlus-update.vpk. If helper cleanup fails, its bubble may remain; do not delete the main VitaPlus app.
- Retains B2 audio recovery, duplicate filtering, adaptive buffer improvements and detailed local diagnostics.
- IMPORTANT: install B3 manually with VitaShell after completely closing VitaPlus. The old B1/B2 installer cannot use the new helper. A later, separately versioned beta is needed to test installation from B3 itself. Save your work in other suspended apps before testing the helper.
- Automated tests and native build are required for publication, but the full installation/relaunch/cleanup cycle has not yet been verified on a physical Vita. Feedback is welcome, including the stage and error code shown if a test fails.
- Stable remains 0.0.6; PS5 remains experimental. Ponte Live diagnostic upload is not integrated.

## Português (Brasil)
- Novo fluxo experimental de atualização interna com instalador auxiliar temporário (PLVTU0001), para contornar o erro 0x80101114 na etapa 8, quando o sistema rejeita a substituição do aplicativo em execução.
- O auxiliar confere novamente o VPK, encerra o aplicativo anterior, instala o VitaPlus, verifica a versão instalada e solicita uma única reabertura. O app principal tenta remover o auxiliar após confirmar sua identidade.
- Contas, configurações e ID do app principal são preservados por projeto. Em caso de falha, o VPK verificado permanece em ux0:Downloads/VitaPlus-update.vpk. Se a limpeza falhar, a bolha do auxiliar poderá permanecer; não exclua o VitaPlus principal.
- Mantidas as melhorias de áudio da B2, recuperação de perdas, filtragem de duplicatas, buffer adaptativo e diagnósticos locais detalhados.
- IMPORTANTE: instale a B3 manualmente pelo VitaShell, com o VitaPlus completamente encerrado. O instalador antigo da B1/B2 não possui o auxiliar. Uma beta posterior, com outra versão, será necessária para testar a instalação a partir da B3. Salve o trabalho de outros aplicativos suspensos antes do teste.
- Compilação nativa e testes automatizados são exigidos para publicação. A instalação, reabertura e limpeza do auxiliar ainda precisam de validação em um PS Vita real. Envie feedback, etapa e código de erro caso falhe.
- A versão estável permanece 0.0.6; PS5 continua experimental. Envio de diagnósticos ao Ponte Live ainda não integrado.
