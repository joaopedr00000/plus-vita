# VitaPlus 0.0.6 B1 — Public Beta

## English

**Community testing requested:** I cannot test this build on my PS Vita right now, so I need your feedback. Automated checks do not replace real-console testing. Thank you to the Reddit users who have already reported successful PS4 streaming and audio issues.

- **My games:** new catalogue filter for games associated with active account-library entitlements that appear in the cloud catalogue. Does not grant new licenses or make unsupported purchases streamable. Existing catalogue and platform filters remain. Library results may be incomplete if Sony's entitlement lookup fails; access is checked at launch. PS5 remains experimental.
- **PS5:** reviewed the latest Con v0.5.2 and pinned Pylux. Adapted Con's session-issued OAuth client identifiers when valid, with original identifiers as fallback, and corrected diagnostic identity to PC (PS5) / H.264. The Vita does not support HEVC hardware decoding; playable PS5 video remains unconfirmed.
- **Internal updater:** revised package header preparation using the installed same-title template and new SFO, native promotion mode, stage/error reporting and installed-version verification. SHA-256 and title ID checks remain. The verified VPK stays in Downloads on failure. The native self-install path still needs testing. If the previous updater only downloads, install B1 manually via VitaShell; the B1 installer is used for future updates.
- Includes all 0.0.6 streaming controls and conservative defaults. Please compare audio options if you experience stutter or delay in The Last of Us Remastered or other games.

**Please report:** Vita model, firmware, game, profile/options, library filter results, PS5 failure stage, and updater stage/error if applicable. Share redacted logs only; never post account JSON, tokens, passwords or vault keys. To receive this beta use Settings → Updates → Beta. Stable stays at 0.0.6. v0.1.0 remains on hold until playable PS5 streaming is confirmed.

**Informem:** modelo, firmware, jogo, perfil/opções, resultados do filtro, etapa da falha do PS5 e etapa/código do atualizador. A 0.0.6 continua estável e a 0.1.0 permanece bloqueada até comprovar streaming jogável de PS5.
