# VitaPlus v0.0.5 — Library Update (Final)

This is a regular release, not a beta or pre-release. **PS5 cloud streaming remains experimental and is currently unavailable for supported gameplay. PS5 support is planned for a future update, with no confirmed date.** PS3 and PS4 remain the focus of supported cloud streaming, subject to Sony account eligibility, region and service availability.

## New library and covers
- Redesigned black-and-gold library: seven compact rows with downloaded thumbnails and platform badges, directly selectable All/PS3/PS4/PS5 tabs, large artwork preview, game information and gold Play button.
- Native Vita keyboard, Square search shortcut, Triangle platform filter, partial title search, clear search, scrolling and touch navigation.
- Automatic background artwork download from allowed PlayStation HTTPS image hosts, with a 350 ms focus delay for uncached covers, immediate RAM-cache reuse and sequential visible-thumbnail prefetch after a 1.2 s settled selection.
- Persistent decoded artwork cache: up to 64 slots (approximately 4 MiB) in `ux0:data/VitaPlus-Covers`; corrupt cache recovery and cancellation of obsolete requests. The folder can be deleted while the app is closed.
- Displays title, platform, available catalogue identifier and the PS5 warning. Playtime and trophy counts are not yet integrated; unavailable data is not shown as zero.

## Streaming and input improvements
- Includes the v0.0.4 adaptive video presentation, bounded audio queues, late-frame recovery and neutral controller recovery after a 100 ms sample outage.
- Independent 4 ms controller sampling, remappable buttons and touch controls; supported external DS3/DS4 controllers.
- Low latency (6 Mbps), balanced (10 Mbps), maximum quality (15 Mbps), adaptive jitter handling, and a bounded retry on eligible network errors.
- Optional HUD: FPS, receive bitrate, RTT estimate, local queue age/depth, decode time, skipped presentations and recovery counts. These are not physical end-to-end input latency measurements.

## Existing features retained
- Sony account login, including local network QR workflow; use only a trusted local network.
- AES-256-GCM account vault, optional password, Remember sign-in and verified matching plaintext import cleanup.
- Manual datacenter selection and account-region discovery policy; no changes to authentication or entitlements.
- 19 locale variants, dark/gold branding and local diagnostic logs (`ux0:data/VitaPlus-Diagnostic-DD-MM-YYYY-HH-MM.log`).

## Installation and validation
Install `VitaPlus-v0.0.5.vpk` with VitaShell. The title ID remains PLVTB0001; APP_VER is 00.21. Privately back up saved account/key files before upgrading. The previous releases are not replaced.

Publication requires automated tests, a VitaSDK build, package/privacy checks and SHA-256 verification. This regular-release designation does not certify physical hardware testing: the new artwork experience and real input-to-display latency still require validation on a real Vita. No working PS5 or GTA VI streaming is claimed.
