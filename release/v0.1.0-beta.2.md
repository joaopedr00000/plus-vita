# Beta 2 — experimental QR pairing

Based on Beta 1; adds optional optical pairing with a temporary key and AES-GCM authenticated encrypted QR. No official Sony device-code flow is claimed. Download the offline HTML helper, sign in on Sony, copy the response, then exchange QR codes with the Vita camera. See [account setup](../docs/ACCOUNT_SETUP.md). No third-party credential relay. Import JSON remains available including PS TV. Hardware validation pending. Beta 2 updates Beta 1 in place, not upstream Plus-Vita. PS5 cloud compatibility remains experimental.
