# VitaPlus v0.1.0 — Unified Interface and Latency

[English](#english) · [Español](#español) · [Português (Brasil)](#português-brasil)

## English

VitaPlus v0.1.0 is the official update built from the published v0.0.5-2 source, with a unified interface, customizable colors, storage organization and low-latency improvements.

### Interface and appearance
- All native menus use the original game catalogue's dark-and-gold design, shared button gradients, focus and touch feedback.
- Live Wi-Fi connection, battery percentage and clock indicators across menus; redesigned account/setup panels and QR pairing screens.
- Shared PlayStation controller icons in the footer, with localized action labels and only the commands relevant to each screen.
- Independent, persistent primary and secondary RGB colors, native hexadecimal color entry, color swatches and restore-original-theme option. The original logo and catalogue layout are preserved. No preset collection or decorative Easter egg icons.
- Fixed regional discovery labels and explanatory text in all 19 supported languages.

### Streaming and responsiveness
- Independently adapted GreenVita v0.3.3 latency improvements: initial software audio buffering targets of 40/40/60 ms for Low Latency/Balanced/Quality, bounded adaptive buffering and small backlog-only PCM shortening.
- Reduced redundant native handheld controller enumeration, retaining independent 4 ms input sampling and compatibility fallbacks.
- Artwork focus delay reduced from 350 to 150 ms; visible thumbnail prefetch from 1,200 to 600 ms, with bounded caches.
- Added 60-second local pipeline timing after warmup. This is not physical button-to-screen latency. H.264 references, hardware decoder protections, display synchronization, quality profiles and recovery remain intact. Actual latency gains need hardware measurements.

### PS5 — EXPERIMENTAL
- Adapted the PS5 session request format from [Con v0.5.2](https://github.com/houqai/Con-app/releases/tag/v0.5.2), which addressed Sony error 002.0011. PS5 authorization, protocol and measured network checks are retained.
- **PS5 cloud streaming is still experimental and playable video is not confirmed.** VitaPlus requests H.264; Con uses HEVC, which the Vita cannot decode in hardware. PS3/PS4 remain the established targets. Availability depends on Sony, your account and network.

### Storage and installation
- Native data moves to `ux0:data/VitaPlus/`: Account, Settings, Imports, Cache/Covers, Cache/PS5-Catalog, Logs/Archive, Captures; Wallpapers and Cache/Themes are reserved, with existing files preserved but no wallpaper rendering in this release.
- Automatic vault key files move only to `ur0:data/VitaPlus/`, separate from encrypted account data. Migration compares duplicates and stops on conflicts; unrelated system and jailbreak files are not changed.
- Install **VitaPlus-v0.1.0.vpk** via VitaShell with Unsafe Homebrew enabled. Back up existing VitaPlus data and dedicated vault keys privately before upgrading. Downgrading may require restoring the former paths. Automated checks and the VitaSDK package gate are required for publication; full hardware validation of the new streaming and migration paths remains pending.

- Solo las claves del almacén automático se trasladan a `ur0:data/VitaPlus/`, separadas de la cuenta cifrada. La migración compara duplicados y se detiene ante conflictos, sin modificar archivos del sistema ni del desbloqueo.

Volver a una versión anterior puede requerir restaurar las rutas originales. La publicación requiere pruebas automatizadas y validación del paquete VitaSDK; quedan pendientes las pruebas completas de streaming y migración en consola.
