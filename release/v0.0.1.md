## Plus-Vita v0.0.1 — First final release / Primeira versão final

Based on the catalogue-r3 build validated on a physical PS Vita. The previous catalogue assembly crash did not recur in the submitted test: HTTPS transfers, all nine assembly phases and account completion succeeded. The public catalogue was empty on the tested account; actual cloud gameplay with an eligible subscription remains unverified.

### Features
- Local QR-code sign-in using your own Sony account. Optional remembered sign-in. The local pairing page uses unencrypted HTTP; use trusted private Wi-Fi and never paste your password.
- Lightweight PlayStation-inspired blue menu, text-only game list, and All / PS3 / PS4 / PS5 filters.
- 19 interface locales and localized pairing page; some technical descriptions remain English. Native complex-script rendering is not fully validated.
- Memory-efficient catalogue assembly, embedded CA bundle, verified TLS through Mbed TLS.
- Cloud streaming client for PS3/PS4 and experimental PS5 H.264, with 720p target, adaptive 6/10/15 Mbps profiles, manual datacenter selection, optional performance HUD and configurable controls.
- Regional discovery hints do not change your account region or bypass subscription, location, or server authorization requirements.

### Instalação e limitações
Instale o VPK pelo VitaShell em um PS Vita com homebrew habilitado. A versão mantém o ID da Beta 3 para atualização direta. O número interno do pacote é 00.17, enquanto a versão pública é 0.0.1. Use a sua própria conta Sony e um plano elegível ao streaming de jogos na nuvem, em região suportada. A disponibilidade é determinada pela Sony; não há garantia de acesso a jogos específicos. PS5 Cloud e a reprodução em conta elegível ainda precisam de validação em hardware real. O login e a conclusão do catálogo foram confirmados no console; a lista ficou vazia no teste sem assinatura. 

Interface azul, catálogo leve com filtros Todos/PS3/PS4/PS5, login QR, melhorias de memória, 19 idiomas, perfis de transmissão, HUD e seleção manual de servidores. Alguns textos técnicos ainda podem aparecer em inglês.

Em caso de problema, envie somente o log `ux0:data/plus-vita-v0.0.1.log`, não o dump de memória. Verifique a integridade do VPK com SHA256SUMS.txt.
