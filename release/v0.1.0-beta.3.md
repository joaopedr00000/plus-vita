# Plus-Vita Beta 3 — Adaptive Streaming
Experimental build based on Beta 2, preserving the PV3 QR protocol and manual server selection.
- Three allocation bitrate profiles: low latency 6 Mbps, balanced 10 Mbps, quality 15 Mbps (default). The selected rate is requested at allocation, not guaranteed. Native Takion congestion feedback remains unchanged. One reconnect after previously decoded video and a qualifying network error requests 20% less, on the same server. No invented in-session bitrate command.
- Adaptive video reordering 16–48 ms based on frame repair/expiry, with bounded IDR recovery on queue pressure, never submit broken dependent frames.
- Reusable decoder submission buffer; native direct RGBA8888 scanout preserved (RGB565 direct display not documented by VitaSDK).
- Adaptive audio prebuffer 50/60/80 ms, up to 110 ms after starvation, fade-in and bounded queue.
- Optional video performance HUD: displayed FPS, received payload kbps, allocation RTT, queue length, reorder wait, last decode time, expired frames and local resync count. Not end-to-end input lag or true RTP jitter.
- Independent 4ms input sampling and H.264 reference guard, FEC and existing PS3/PS4 routes retained.
Hardware tests required; PS5 gameplay and GTA VI remain unconfirmed. Localization and RGB565 GXM presentation are separate future work. Profile choices are in-memory. Use the existing Beta 2 offline helper.
