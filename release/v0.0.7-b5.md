## English
**PS5 Portal authorization experiment**
- One-time preference migration resets only the PS5 mode to Portal; other settings remain intact. Advanced streaming options displays the active PS5 mode explicitly and allows manual PC selection. Both request H.264/AVC hw4.1 exclusively, 720p, SDR; no HEVC fallback.
- Each Gaikai request uses one consistent session envelope, captured at provisioning start. UI reports the actual envelope recorded by the Gaikai worker, not an inference from UI preferences. No silent switch to PC.
- Aligns PS5 OAuth service parameter with Con 0.5.2. Checks presence of both server-issued authorization codes, session ID and key before authorization; logs only a numeric readiness mask, key-update status and selected envelope. Retains existing session-key response compatibility and OAuth code normalization. No credentials, tokens or raw response bodies are added to diagnostic logs.
- HTTP 400 at authorization is not yet resolved on hardware. Sony may still reject H.264 or the session. Entitlements, account, region and authorization checks remain in effect. PS3/PS4 and B4 features retained. PS2 classic classification still needs verified catalogue data.
- Recommended optional [Wi-Fi Turbo](https://github.com/juanjsebgarcia/vita-turbo-wifi) ([downloads](https://github.com/juanjsebgarcia/vita-turbo-wifi/releases)); check firmware compatibility. Not a guaranteed fix.
